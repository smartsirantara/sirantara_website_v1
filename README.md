# Sirantara Smart Solutions

Premium website template for a smart home, security and automation solutions business based in Sirsi, Karnataka.

## Features

- React + Vite 
- Ant Design UI integration
- Tailwind CSS styling
- Dark / light theme toggle
- Responsive modern layout
- Contact form with WhatsApp and call links
- SEO metadata and keyword optimization
- Placeholder sections for portfolio, FAQ and blog

## Installation

1. Install Node.js and npm.
2. Run `npm install`.
3. Run `npm run dev`.
4. Build with `npm run build`.

## Pages

- `/` - Homepage
- `/about` - About page
- `/contact` - Contact page
